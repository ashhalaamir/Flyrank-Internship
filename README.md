# FlyRank Internship - Capstone Project

## Overview
This repository contains my capstone project for the FlyRank internship program.
The goal is to build a polished, user-friendly front-end that demonstrates modern web development practices. The project will evolve over the internship as requirements are defined.

## Tech Stack
- Node.js (LTS)
- React 19
- Vite
- React Hook Form + Zod (form validation)

## Setup Instructions
1. Clone this repository
2. Run `npm install`
3. Run `npm start` (or `npm run dev`)
4. Open `http://localhost:5173`

## Scripts
- `npm start` — start the dev server
- `npm run build` — production build
- `npm test` — run unit tests

## Project Structure
```
src/
  components/
    FormField.jsx       # Reusable labeled field wrapper
    SettingsForm.jsx    # Settings form with validation
  validation/
    settingsSchema.js   # Zod validation rules
  App.jsx
  main.jsx
  index.css
```
